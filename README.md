# Feestdagen Nederland & Suriname → iOS Agenda

Nederlandse en Surinaamse feestdagen samengevoegd (2026–2031). In de titel staat wie er vrij is:
🇳🇱🇸🇷 = vrij in NL én Suriname, 🇸🇷 = vrij in Suriname, 🇳🇱 = vrij in Nederland.

## Toevoegen
Open op iPhone: https://rashruf.github.io/feestdagen-calendar/ → Abonneer → Account: iCloud.

## Bron
Datums uit de Python-bibliotheek `holidays` (NL en SR). Ied-ul-Fitr en Ied-ul-Adha zijn schattingen; de Surinaamse overheid maakt de precieze dag kort vooraf bekend. Data staat in `_data/feestdagen.csv`.
